# 🏍️ Honda Motos Brasil

Uma landing page moderna e elegante desenvolvida para entusiastas de motociclismo, focada na exibição de modelos, performance e estilo de vida sobre duas rodas.

## 📝 Sobre o Projeto
Este site foi desenvolvido para consolidar conhecimentos em desenvolvimento web front-end. O foco foi criar uma interface visualmente atraente, utilizando semântica **HTML5** e técnicas modernas de estilização com **CSS3**.

### ⚡ Principais Funcionalidades
- **Layout Responsivo:** O site se adapta perfeitamente a celulares, tablets e desktops.
- **Seção Hero:** Destaque principal com imagem de alta qualidade e chamada para ação (CTA).
- **Galeria de Modelos:** Exibição de motos com cards estilizados.
- **Menu de Navegação:** Navegação fluida entre as seções da página.
- **Hover Effects:** Efeitos visuais interativos nos botões e imagens.

## 🛠️ Tecnologias Utilizadas
Para manter o projeto leve e performático, utilizei apenas tecnologias puras:

* **HTML5:** Estruturação semântica e acessível.
* **CSS3:** Estilização, sistema de cores, fontes customizadas e layouts com Flexbox/Grid.
